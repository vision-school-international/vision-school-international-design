## Handling rules

- Keep these files inside this private planning repository.
- Do not publish them on the Vision School website or copy them into public documentation.
- Do not treat transcript wording as approved requirements, claims, translations, testimonials, or ministry copy.
- Do not add recordings, passwords, login codes, API keys, booking confirmations, payment details, private contact information, or pastoral information.
- If a transcript is later found to contain restricted information, remove the exposed value from the current branch, rotate or invalidate the value when applicable, and alert the project owner.

The three source files were checked before commit for literal email addresses, phone numbers, passwords, API tokens, booking confirmation codes, and payment-card numbers. No such values were found. The conversations do discuss authentication and travel workflows at a general level, so they should still be treated as internal.
