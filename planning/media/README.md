# Media planning

Use this folder for planning notes about media sources, public-use permission, consent, approval, captions, alternative text, and intended placement.

The current detailed source log remains [IMAGE-SOURCING.md](../../IMAGE-SOURCING.md) while its open design pull request is reviewed. It can be moved into this folder in a later documentation pull request after that work is merged, without changing the media files themselves.

Do not add an image, video, or testimony here merely because it is publicly visible elsewhere. Record the source and obtain the required Vision School or ministry approval before treating it as production-ready.
