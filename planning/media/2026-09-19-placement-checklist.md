# Media and wording handoff

The site can be laid out now, but a resource folder is not publication approval. Christina and the ministry/content owners should select the exact file for each slot and confirm its intended use. HQ-managed Google Drive is the current handoff location; no new storage service is needed.

| Website slot | What the team should supply | Approval still needed |
|---|---|---|
| Main introduction | One welcoming, relevant group image or short clip, and a short explanation of Vision School | Exact crop/clip, organizational wording, rights and visible-person consent where required |
| Course explanation | Approved course description and an image of a real learning setting | Claims, curriculum wording, class context, and media use |

| Branch cards/details | Optional local image, useful alt text/caption, confirmed branch name/location and public contact | Correct branch association, public venue/contact consent, and no private travel details |
| Closing invitation | Approved class invitation and destination | Current Church Center or directory link |

For each selected asset, record: Drive file link, intended slot, public-use permission, approver, approved crop/clip, caption/alt text, language, and any expiry/restriction. These are a small checklist, not a request to build a new asset-management system.

Use imagery that reflects the real community and fits the section. Do not infer ethnicity from people's appearance, label individuals by assumed background, or attach a generic gathering photo to a specific branch as if it depicts that branch.

Until approval, leave the slot absent or visibly mark a neutral design placeholder. The branch demo's neutral SVG is not a real photograph and is not a proposed brand asset. No new video still or third-party photograph was selected for publication in this work.
